# CosyVoice3 推理依赖（AMD ROCm / Windows 适配版）
# 由上游 CosyVoice/requirements.txt 裁剪而来，差异说明：
#   - torch / torchaudio 已单独安装 ROCm 版（2.9.1+rocm7.2.1），此处不重复声明，
#     也绝不引入上游的 --extra-index-url .../cu121（会把 CUDA 版 torch 装回来）。
#   - onnxruntime 使用 CPU 版：Windows ROCm 不提供 onnxruntime GPU EP，
#     speech_tokenizer_v3.onnx / campplus.onnx 在 CPU 上推理，占比很小可忽略。
#   - 裁掉训练/部署专用且推理路径不 import 的包：
#     deepspeed(Linux)、tensorrt-cu12(Linux)、gradio、fastapi/uvicorn(WebUI)、
#     grpcio(GPU 服务)、pyarrow、pyworld、phonemizer、rootutils、tensorboard。
#   - lightning 不能裁：Matcha-TTS 的 matcha/utils/pylogger.py 依赖 lightning 的
#     rank_zero_only，加载 cosyvoice.flow.flow_matching 时会触发。上游锁 2.2.4（配套
#     torch 2.3），此处放宽到 >=2.4 以适配 torch 2.9。
#   - gdown / matplotlib / pyarrow 也不能裁：cosyvoice3.yaml 在解析时会实例化
#     cosyvoice.dataset.processor（顶层 import pyarrow）与 matcha.utils.utils
#     （顶层 import gdown、matplotlib.pyplot）。matplotlib 必须锁 <3.9，否则会强制
#     把 numpy 升到 2.x，破坏 numpy==1.26.4（numba/librosa/onnxruntime 1.18 的要求）。
#   - pyworld 不在此清单：需要 MSVC 编译，Windows 上通常装不上。它与推理无关
#     （仅训练做 F0 提取），由 setup 脚本给 cosyvoice/dataset/processor.py 打可选导入补丁。
