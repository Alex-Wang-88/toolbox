# 图片转视频 · 界面重构与"文稿审阅"流程改造计划

> 状态：已实现（待你本地启动试用，2026-07-09 完成）
> 定位：团队/个人自用工具，**不考虑商业化**——不做竞品调研、市场分析，专注"好用 + 好看"

---

## 一、你的需求（已记录）

1. **项目定位**：团队/个人工具，不商业化。
2. **界面要尽可能人性化**。
3. **AI 返回文稿后，要把每一页的文稿展示给用户**（逐页可见）。
4. **用户可以增删文字**（每页文稿可编辑 / 增减内容）。
5. **点击"生成"才真正开始生成视频**——即"先审稿、后生视频"，两步彻底分离。
6. **界面要更美观，尤其是 GPU 加速版**：因为功能更多了，UI 需要重构来承载。

---

## 二、现状诊断（为什么现在做不到）

当前流水线（`web_server.py` 的 `run_video_generation`）是单线程一把梭：

```
上传图片 → batch_upload_images(图床) → generate_full_speech_result(AI文稿)
        → batch_generate_tts(TTS) → generate_srt_subtitle(字幕) → generate_video(视频)
```

- AI 文稿（`speech_dict`，按图片 global_id 一一对应）**只在后端内存里生成，从不返回前端**。
- 前端点"拆分并预览"实际只做"上传+转图片"，点"开始生成"后文稿同步生成且不可见、不可改。
- 所以"逐页审阅/增删文字"当前完全没有入口。

> 注：文稿与图片是 **1:1** 对应的（每张图一段话术），这点对重构非常有利——"页"= "图"。

---

## 三、后端改造（贝洛奇 / 高见远）

### 3.1 把流水线从中间劈开

**新增 `POST /api/generate-manuscript`**
- 输入：已上传图片的 `files` / `image_items`（与现有 `/upload` 返回结构一致）
- 内部：`batch_upload_images` → `generate_full_speech_result`
- 返回：
  ```json
  {
    "success": true,
    "video_filename": "AI建议文件名",
    "manuscript": [
      {"page": 1, "file": "...", "name": "...", "preview_url": "...", "text": "该页AI文稿"},
      {"page": 2, "file": "...", "name": "...", "preview_url": "...", "text": "..."}
    ]
  }
  ```

**改造 `POST /api/generate`**
- 新增可选字段 `manuscript: [{file, text, ...}]`
- 若传了 `manuscript`：**跳过 AI 调用**，直接用用户编辑后的文稿构建 `speech_dict` 进入后续 TTS→字幕→视频
- `run_video_generation` 增加 `speech_dict_override` 参数；缺省时仍走原 AI 流程（兼容命令行入口）

### 3.2 GPU 加速版信息暴露（让功能"可见"）

- 扩展 `/api/hardware` 或新增 `/api/config`，返回：
  - `gpu_accel`: 是否启用（`USE_GPU_ACCEL`）
  - `whisper_model`: faster-whisper 模型大小（GPU 才有效）
  - `nvenc_preset` / `nvenc_cq`: NVENC 预设与画质
  - `cuda_device`: 设备名（如 `NVIDIA GeForce RTX 5060`）
- 目的：UI 能展示"GPU 已启用 / 字幕对齐方式 / 编码档位"，并把这些变成**可调开关**（见第四节）。

## 四、前端重构（颜好看 / 贾思敏）

整体改为**三步向导（Stepper）**，把"审稿"做成独立、可见的一步：

```
① 素材  ──▶  ② 文稿（审阅/编辑）  ──▶  ③ 生成
```

### Step ① 素材
保留现有能力：拖拽上传、排序、删除、语音克隆、字幕开关、输出目录/名称。
→ 按钮由"拆分并预览"改为 **"生成文稿"**（触发 3.1 的新接口）。

### Step ② 文稿（核心新增）
- **点"生成文稿"时页面数量即锁死**（等于 Step①已上传图片数），审阅阶段**只改文字、不改页数**：不做新增页、不做删整页、不做拖排序。
- 生成中： spinner + "AI 正在为每页写讲解…"
- 生成后：**每页一张卡片**
  - 左侧：该页缩略图
  - 右侧：**可编辑文本框**（即该页文稿，可自由增删文字）+ 字数提示
  - 卡片操作：仅文本编辑（增/删文字），无删页/排序/单页重生成
- 顶部：**AI 建议文件名**（可改）、**"全部重生成"**（重跑全部 AI 文稿，单页重生成不做——消耗本就很低）、**"下载文稿"**（导出逐页文本/Markdown）、**"应用并进入生成"**
- 逻辑：编辑后点"生成视频"才带着这份（可能改过的）文稿进入 Step ③

### Step ③ 生成
- 点"生成视频" → 进度条 → 完成下载（沿用现有进度/下载/日志）
- 文稿始终保留在前端状态，想再改可一路返回 Step ②

### GPU 加速版专属面板（按用户要求做"更详细"）
- **语音 / 音色管理**：做成独立、显眼的区块，把"不同人音色"的管理做完整：
  - 列表展示每个音色（默认 / 预设 / 克隆的"某人的声音"），含名称、类型
  - **增加**：上传参考音频 → 训练克隆（已有，需更显眼、步骤更清楚）
  - **重命名**、**删除** 克隆音色（已有，需入口更明确）
  - **下载**：导出某个已训练克隆音色的参考音频（即"训练的文稿下载"的对应实现）
- **文稿下载**：Step② 顶部"下载文稿"按钮，把逐页 AI 文稿导出为 `.txt` / `.md`
- **性能 / GPU 折叠区**（有 GPU 才展开）：
  - 展示：GPU 是否启用、CUDA 设备名
  - 字幕对齐方式：`faster-whisper 精确对齐` / `文本长度估算`（只读展示）
  - NVENC 编码档位：`极速(p1)` / `均衡` / `画质(p7)`（只读展示，暂不做 UI 改写）
- 让"多了功能"这件事在界面上被看见、被用起来。

### 美观 / 人性化方向
- 更克制的配色与更大留白，卡片化排版，统一圆角/阴影
- 步骤条清晰指示当前所处阶段
- 友好的空状态引导（"拖拽图片开始"）
- 轻量过渡动画（卡片出现、进度）
- 响应式（窄屏下文案卡片上下堆叠）
- 记住上次设置（输出目录、字幕模式等，本地持久化）

## 五、我的建议（供你拍板）

1. **删除整页 = 删该图**：用户删一页文稿就同步从视频里去掉这张图，语义最自然。
2. **加"重生成这一页"**：改了一页不满意，只重跑那一张的 AI，不必全盘重来（省时、省 API）。
3. **"增加文字"的边界建议**：
   - 页内文本增删 ✅ 必做
   - 删除整页 ✅ 必做
   - **新增一整页（带新图）**：建议通过"再次上传"实现，而不是做"无图空白页"（无图页生成视频没意义）
4. **AI 建议文件名**放在文稿页顶部，可改，生成视频时直接用。
5. **GPU 开关做成 UI 可调**（而不仅是展示），让"功能多了"真正被用起来。
6. 可选增强：**单页朗读试听**（用 edge-tts 试听该页配音），帮用户判断文稿长度是否合适。

## 六、已确认决策（用户 2026-07-09 回复）

- **Q1（页数）**：只做文字编辑。**点"生成文稿"时页面数量即锁死**（= 已上传图片数），审阅阶段不增页、不删整页、不拖排序。
- **Q2（重生成）**：保留**"全部重生成"**；**不做"单页重生成"**（消耗极低，没必要）。
- **Q3（GPU 功能详尽度）**：GPU 相关功能要做"更详细"：
  - 语音/音色管理做成显眼独立区块：不同人音色的**增加 / 删除 / 重命名** 入口更明确；
  - 新增**已训练克隆音色的下载/导出**；
  - 新增**文稿下载**（导出逐页 AI 文稿）；
  - 性能/GPU 区展示 GPU 状态、字幕对齐方式、NVENC 档位（本轮**只读展示**，暂不做 UI 改写配置）。
- **Q4（配色）**：换一套**不那么刺眼**的配色，**不需要非常黑**（柔和浅色主题，低饱和、护眼）。

> 注：若"训练的文稿下载"你指的是"下载已训练音色文件"，已纳入上述"导出克隆音色"；若指别的，开工后告诉我再补。

## 八、GPU 语音加速总开关 + 依赖自动安装（已实现 2026-07-09）

### 需求（用户第七轮）
- GPU 不符合要求 → 直接走默认 edgeTTS，不显示 GPU 开关。
- GPU 符合要求 → 显示"开启 GPU 加速"按钮；按下后检测依赖，缺依赖则弹窗提示下载大小/时间，给两个选项：
  1. 安装并下载权重（含 XTTS ~1.8GB）
  2. 仅安装引擎（跳过权重）
- 硬件门禁用 `nvidia-smi` 检测（不依赖 torch）。

### 落地（src/gpu_setup.py + src/web_server.py + static/index.html）
- **硬件门禁** `detect_hardware_capable()`：`nvidia-smi -L` + `--query-gpu=name,memory.total`，N 卡且显存≥6GB 才 `capable`。无环境也能安全调用。
- **依赖检测** `check_dependency()`：复用 `voice_clone.resolve_external_python()` + `_verify_external_python()`（真能 import torch+TTS 才算就绪）。
- **自动安装** `run_gpu_install(task_id, download_weights, data_root)`：后台线程，装 Python3.11→venv→torch cu130→TTS(含 MSVC 兜底)→验证→(可选)XTTS 权重→写 `app_data/xtts_python.txt` 首行（与 voice_clone 自动接上）。每步进度写 `tasks[task_id]`，前端用现有 `/api/status/<task_id>` 轮询。
- **三个接口**：`GET /api/gpu-voice/status`（硬件/依赖/开关/安装进度/估值）、`POST /api/gpu-voice/enable {"enabled"}`（依赖缺失时回 `needs_install:true`）、`POST /api/gpu-voice/install {"download_weights"}`（后台装，返回 task_id）。
- **前端 UI**：性能/GPU 区"旁白/音色 GPU 加速"卡片；硬件不符只显示提示语；符合则显示开关；缺依赖弹窗（~4.5GB / ~12min 估值 + 两选项）+ 进度条轮询 + 失败重试。

### 验证
- Flask 测试客户端实测：`/status` 返回真实 `NVIDIA GeForce RTX 5060 Laptop GPU` / 8GB / `hardware_capable=true`；`/enable` 切换并落盘 `app_data/gpu_voice_settings.json`；契约对齐（依赖已就绪时 `needs_install=false`）。`/install` 仅验证返回 task_id 契约，未实跑下载。
