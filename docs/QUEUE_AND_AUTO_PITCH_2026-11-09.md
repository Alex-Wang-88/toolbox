# 统一队列、自动音高与界面重构

日期：2026-11-09。

## 已交付行为

- 一个 Flask 服务内的所有生成任务按提交顺序串行执行。空闲时立即开始，完成、失败或取消后接续下一项。
- 接入素材导入与拆页、AI 文稿、单段/批量配音、AI 唱歌、NCM 转换、生图，以及克隆音色创建、音频分析、逐字稿识别。音频试听、上传预检和配置查询仍为辅助操作。
- `/queue` 显示正在执行、等待和最近记录；`GET /api/queue` 返回状态。等待任务可立即取消并清理临时文件；运行中的取消在当前处理步骤结束后释放资源，不会提前启动下一项。
- 各页面都有队列状态入口；“继续创建任务”允许同页提交更多任务，先前任务的结果可从队列下载。页面刷新和跳转不影响后台任务。
- 生图/音视频资源模式在轮到任务时自动切换。打开页面不会切换模式；队列运行时禁止更换克隆引擎、输出目录、删除被引用的音色或背景音乐、清理素材。
- 兼容原有同步 API；网页的主要生成入口使用异步响应。音色相关上传先保存到临时文件，避免请求结束后文件被 Flask 关闭导致任务失败。

## 页面层级

一级页面保留输入、音色、输出格式、主操作、当前进度和生成结果。公共脚本将现有控制节点移到同页二级路由，保留已选文件、参数和事件监听。

| 页面 | 二级入口 |
| --- | --- |
| AI 唱歌 | 音高与质量、转换记录 |
| 语音合成 | 音色管理、语速与音量、配音记录 |
| 讲解视频 | 音色管理、音乐与输出、运行环境 |
| AI 生图 | 采样设置 |

二级路由示例：`/singing#advanced/pitch`。返回操作、浏览器前进/后退和直接打开均可使用。音频转换的格式选择属于核心操作，留在一级页面。

## 自动音高验证

自动匹配根据源人声中位音高和参考音频的 P10–P90 音域判断是否移调，最多正负 5 半音。手动移调覆盖自动计算；原曲模式下人声与伴奏始终使用同一个整体移调值。原曲模式和自动音域模式不再叠加 Seed-VC 的独立 F0 中位对齐，以免人声与伴奏调性不一致。非法、无声或探测失败的输入保留不移调的回退路径。

使用已存在的本地歌曲结果裁出约 8 秒样本和已登记的参考音色，真实运行 Demucs、RMVPE、Seed-VC 和 FFmpeg：

1. 原始短样本中位约 249Hz，位于目标音域内，实际移调 0 半音并完成输出。
2. 将短样本提高八度后再次运行，中位约 500Hz，目标音域约 145–273Hz；实际自动下调 5 半音，任务日志记录伴奏同步下调与混音成功。
3. 第二次输出 7.919 秒，RMS 0.0814、峰值 0.4002，样本均为有限值，削波比例 0。
4. 独立 440Hz 音调经同一伴奏移调函数下调 5 半音后，FFT 主频 329Hz，理论值 329.63Hz。
5. 唱歌执行期间提交逐字稿任务，接口返回等待状态、队列第 1 位；取消后该任务未执行，唱歌正常完成。

证据保存在本机 `output/verification/queue-auto-pitch-20261109/`：任务 JSON、信号检查、输出 WAV、界面截图。样本测试证明流程、移调和输出有效，不能代替主观听感或所有歌曲/音色的质量评价。

## 运行边界

队列和最近记录保存在当前服务内存中。切页或刷新不会丢失；停止或重启服务后不会自动恢复未完成任务，已导出的文件保留。此版本按单服务进程运行，不支持多个 Flask 实例之间共享队列。运行中取消采用处理阶段之间的检查，正在执行的模型子进程可能需要等待当前阶段结束。

本次沿用并保留工作区原有未提交改动，没有构建 exe 或提交 Git。
