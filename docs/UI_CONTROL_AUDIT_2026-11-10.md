# 全站按钮尺寸与布局检查

完成日期：2026-11-10。

## 修复

- 常规操作、导航、二级入口、下载、取消、试听、预设、音色管理、主题设置及关闭按钮统一使用 44px 最小高度和点击宽度。
- 同级操作按钮统一为 14px 字号、20px 行高；保留导航文字、图标等各自的排版用途。
- 并排主/次按钮、下载/重新生成、输出目录输入/浏览等控件对齐。移除下载按钮的额外上边距，禁用前后保持尺寸不变。
- 长文件名下载按钮限制在容器宽度内，允许换行并增加高度，避免文字裁切或越界。
- 音频预览、结果和历史播放器统一为 44px 高。
- 修复双栏工作区右侧面板的额外上边距。
- 素材页窄屏下改为分行布局，为图片、排序、删除和参数控件保留空间；排序和删除点击区不再挤在窄列里。
- 主题颜色选项使用自适应列数，关闭和色块按钮保留完整点击区域。

上传区、图片预览、步骤卡片和色轮按其内容保留较大的尺寸。长文字按钮允许多行，44px 为其最小高度。
