# TOOLBOX UI 打磨与截图对比

日期：2026-11-10。基于用户确认的方向，在现有未提交版本之上做轻度打磨，保留功能、配色和工作流。

## 方向与审计

- 产品：素材、配音及音视频处理工作台。
- 性格：沉稳、准确、专注。
- 场景：剪辑台；沿用现有蓝色与中性色。
- 重点：上传、输入和生成结果。
- 识别细节：步骤编号、文件计数与任务状态。

原界面已有共享样式和完整导航。主要问题是小字偏多、标题字重过高、不同页面宽度变化，以及高级设置在页面标题之前造成层级倒置。采用 polish 模式，不新增装饰图片或产品能力。

## 九轮处理

1. 间距：共享小间距改为 8px；面板内部 24px、工作区栏间 24px，手机保留 16px 面板内边距。
2. 颜色：保留蓝色；提高浅色弱文本对比，深色弱文本与现有 muted 保持一致；队列条改为底部分隔线。
3. 图标：保留已有线形图标和上传图标，不引入新的图标系统。
4. 文案：审查现有产品文案，保留具体功能描述和 AI 可选路径，不增加宣传语或未经验证的数据。
5. 排版：元信息从 11px 提升至 12px，辅助文字 13–14px；页面标题 28–36px、500 字重，面板标题至多 600。
6. 布局：六页统一 1280px 最大宽度；设置入口移至标题之后，保持 DOM 与阅读顺序一致；视频侧栏 360px，窄屏继续按原规则堆叠。
7. 细节：文件计数取消胶囊底色；导航选中态使用现有浅蓝，步骤选中态以细色条标识，状态标签统一小圆角。
8. 视觉：素材上传目标增加内边距和高度，保留现有真实素材、输入及结果展示，不增加概念插图。
9. 动效：保留原有短时反馈与 reduced-motion 支持，不新增循环动画。

## 验证与产物

- 改前先拍摄六页：素材、TTS、唱歌、音频转换、生图、队列；1440px 与 375px，共 12 张。
- 改后以相同页面、浅色主题、屏宽及 1000px 视口高度再拍摄 12 张；不注入任务和示例状态，用于直接比较。
- 浏览器审计另使用隔离上下文和测试数据，覆盖 18 种页面/业务状态、1440/768/375px、浅色/深色，共 228 份状态记录、2958 次控件测量：尺寸/文字越界、页面横向溢出、并排高度不一致、双栏顶部不齐和脚本异常均为 0。
- 上传区宽度修正后，追加首页和素材页检查：36 份状态、528 次控件测量，上述异常均为 0。
- 前端流程 pytest：21 passed，5 subtests passed；公共 class 样式审计通过。
- 浏览器实查高级设置返回、升降调设置保留及队列导航通过。
- 本次未执行真实音视频合成或 GPU 推理；浏览器审计的示例结果不代表新生成产物。未覆盖真实手机、系统文字缩放或所有平台原生播放器内部控件。
